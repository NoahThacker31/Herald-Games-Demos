# Feedback and bug reports

Join https://discord.gg/AGjSTsFVs and use the dedicated channel for your game for development notes, FAQs and discussion.

For GitHub reports, include:
- Game name and full demo version/build identifier.
- Operating system and whether you used the installer or portable edition.
- Steps to reproduce, expected behavior, and actual behavior.
- Relevant screenshots, without private information.

This is a public demo distribution repository. Please do not upload proprietary source code, credentials or personal data.
