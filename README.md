## Games and downloads

Each game's branch contains its documentation and a version history. Executables are attached to **GitHub Releases**, rather than stored in Git history. Download the installer or portable executable; you do not need to clone this repository or install Git.

## Development notes, FAQs and feedback

[Join the Herald Games Discord](https://discord.gg/AGjSTsFVs). Use the dedicated channel for the game you are playing to find development notes, FAQs, known issues and discussion, and to share bug reports, UI nice-to-haves and other feedback.

You can also [open a GitHub issue](../../issues). Please name the game and version, your operating system, steps to reproduce the issue, and what you expected versus what happened. Screenshots are welcome; avoid posting private information.
